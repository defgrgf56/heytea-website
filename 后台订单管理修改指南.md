# 后台订单管理修改指南

## 🚨 当前问题

**问题描述**：
- 前台用户提交订单后，订单状态为 `pending`（待确认）
- 后台管理系统能看到订单，但**没有"确认订单"按钮**
- 导致订单卡在 `pending` 状态，无法进入后续流程（制作 → 配送 → 完成）

**影响**：
- ❌ 订单无法处理
- ❌ 商家无法接单
- ❌ 业务流程中断

---

### **需要修改的项目**：`heytea-admin`（后台管理系统）

### **需要修改的文件**：
- 订单列表页面（可能是 `OrderList.vue` 或 `Orders.vue`）
- 订单详情页面（可能是 `OrderDetail.vue`）

## 🔄 完整的订单状态流转

```
pending (待确认)
  ↓ [后台点击"确认订单"]
confirmed (已确认)
  ↓ [后台点击"开始制作"]
preparing (制作中)
  ↓ [后台点击"开始配送" 或 "完成订单"]
delivering (配送中) [可选]
  ↓ [后台点击"完成订单"]
completed (已完成)
```

**取消流程**：
```
pending / confirmed
  ↓ [后台点击"取消订单" 或 "拒绝订单"]
cancelled (已取消)
```

## 📊 后端 API 说明

### **更新订单状态接口**

```http
PATCH /admin/orders/:id/status
Authorization: Bearer <admin_token>
Content-Type: application/json

{
  "status": "confirmed"  // 或 "preparing", "delivering", "completed", "cancelled"
}
```

**权限要求**：
- ✅ 后台工作人员 Token
- ❌ 普通用户 Token（返回 403）

**可用的状态值**：
- `pending` → `confirmed`（确认订单）
- `confirmed` → `preparing`（开始制作）
- `preparing` → `delivering`（开始配送）
- `preparing` → `completed`（直接完成，跳过配送）
- `delivering` → `completed`（完成配送）
- `pending/confirmed` → `cancelled`（取消订单）

## 🕐 时间格式化问题

### **问题说明**

后端返回的时间是 ISO 8601 格式的 UTC 时间：
```
2026-08-11T02:15:11.587Z
```

这是 UTC 时区的时间，需要转换为本地时间（中国时区 UTC+8）：
```
2026-08-11 10:15:11  // UTC+8
```

### **解决方案**

在后台管理系统中添加时间格式化工具函数：

```javascript
// utils/datetime.js 或直接在组件中定义

/**
 * 格式化 ISO 时间为本地时间
 * @param {string} isoTime - ISO 8601 格式时间
 * @param {boolean} showSeconds - 是否显示秒
 * @returns {string} 格式化后的时间字符串
 */
export function formatDateTime(isoTime, showSeconds = true) {
  if (!isoTime) return ''
  
  const date = new Date(isoTime)
  
  // 检查是否为有效日期
  if (isNaN(date.getTime())) return isoTime
  
  const year = date.getFullYear()
  const month = String(date.getMonth() + 1).padStart(2, '0')
  const day = String(date.getDate()).padStart(2, '0')
  const hours = String(date.getHours()).padStart(2, '0')
  const minutes = String(date.getMinutes()).padStart(2, '0')
  const seconds = String(date.getSeconds()).padStart(2, '0')
  
  if (showSeconds) {
    return `${year}-${month}-${day} ${hours}:${minutes}:${seconds}`
  } else {
    return `${year}-${month}-${day} ${hours}:${minutes}`
  }
}

/**
 * 格式化为相对时间（如：刚刚、3分钟前、2小时前）
 */
export function formatRelativeTime(isoTime) {
  if (!isoTime) return ''
  
  const date = new Date(isoTime)
  const now = new Date()
  const diff = now - date
  
  const seconds = Math.floor(diff / 1000)
  const minutes = Math.floor(seconds / 60)
  const hours = Math.floor(minutes / 60)
  const days = Math.floor(hours / 24)
  
  if (seconds < 60) return '刚刚'
  if (minutes < 60) return `${minutes}分钟前`
  if (hours < 24) return `${hours}小时前`
  if (days < 7) return `${days}天前`
  
  return formatDateTime(isoTime, false)
}
```

## � 新订单提醒功能

### **功能说明**

当前台用户下单后，后台管理系统应该实时提醒工作人员有新订单需要处理。

### **实现方案**

#### **方案 1：定时轮询（推荐，简单易实现）**

在后台订单列表页，定期检查是否有新的 `pending` 订单。

```javascript
// 在订单列表页面添加

import { ref, onMounted, onUnmounted } from 'vue'
import { ElNotification } from 'element-plus'

// 上次检查的订单数量
let lastOrderCount = 0
let checkTimer = null

// 检查新订单
async function checkNewOrders() {
  try {
    // 获取待确认订单数量
    const response = await orderApi.getOrders({ 
      status: 'pending',
      page: 1,
      pageSize: 1  // 只需要总数
    })
    
    const currentCount = response.total || 0
    
    // 如果有新订单（数量增加）
    if (lastOrderCount > 0 && currentCount > lastOrderCount) {
      const newOrderCount = currentCount - lastOrderCount
      
      // 显示通知
      ElNotification({
        title: '新订单提醒',
        message: `有 ${newOrderCount} 个新订单待确认`,
        type: 'warning',
        duration: 0,  // 不自动关闭
        position: 'top-right',
        onClick: () => {
          // 点击通知跳转到订单列表
          router.push('/orders?status=pending')
        }
      })
      
      // 播放提示音（可选）
      playNotificationSound()
      
      console.log('🔔 新订单提醒:', newOrderCount, '个新订单')
    }
    
    lastOrderCount = currentCount
  } catch (error) {
    console.error('检查新订单失败:', error)
  }
}

// 播放提示音
function playNotificationSound() {
  try {
    const audio = new Audio('/notification.mp3')  // 需要准备提示音文件
    audio.volume = 0.5
    audio.play().catch(err => {
      console.warn('播放提示音失败:', err)
    })
  } catch (error) {
    console.warn('提示音播放失败:', error)
  }
}

// 启动定时检查
function startOrderCheck() {
  // 初始化：记录当前订单数
  checkNewOrders()
  
  // 每30秒检查一次
  checkTimer = setInterval(() => {
    checkNewOrders()
  }, 30000)  // 30秒
  
  console.log('🔔 新订单检查已启动（每30秒）')
}

// 停止定时检查
function stopOrderCheck() {
  if (checkTimer) {
    clearInterval(checkTimer)
    checkTimer = null
    console.log('🔔 新订单检查已停止')
  }
}

// 在订单列表页面的生命周期中使用
onMounted(() => {
  startOrderCheck()
})

onUnmounted(() => {
  stopOrderCheck()
})
```

#### **方案 2：浏览器通知 API（更醒目）**

使用浏览器原生通知 API，即使后台页面最小化也能看到通知。

```javascript
// 请求通知权限
async function requestNotificationPermission() {
  if (!('Notification' in window)) {
    console.warn('浏览器不支持通知API')
    return false
  }
  
  if (Notification.permission === 'granted') {
    return true
  }
  
  if (Notification.permission !== 'denied') {
    const permission = await Notification.requestPermission()
    return permission === 'granted'
  }
  
  return false
}

// 显示浏览器通知
async function showBrowserNotification(title, body) {
  const hasPermission = await requestNotificationPermission()
  
  if (hasPermission) {
    const notification = new Notification(title, {
      body: body,
      icon: '/logo.png',  // 通知图标
      badge: '/badge.png',
      tag: 'new-order',  // 相同tag的通知会被替换
      requireInteraction: true  // 需要用户交互才关闭
    })
    
    // 点击通知时聚焦窗口
    notification.onclick = () => {
      window.focus()
      router.push('/orders?status=pending')
      notification.close()
    }
  }
}

// 检查新订单时使用浏览器通知
async function checkNewOrders() {
```

#### **方案 3：WebSocket 实时通知（最佳，需要后端支持）**

如果后端支持 WebSocket，可以实现真正的实时推送。

```javascript
// WebSocket 连接
let ws = null

function connectWebSocket() {
  ws = new WebSocket('wss://haonan.online/api/tea-demo/ws')
  
  ws.onopen = () => {
    console.log('🔌 WebSocket 已连接')
    // 发送认证信息
    ws.send(JSON.stringify({
      type: 'auth',
      token: localStorage.getItem('token')
    }))
  }
  
  ws.onmessage = (event) => {
    try {
      const data = JSON.parse(event.data)
      
      // 收到新订单通知
      if (data.type === 'NEW_ORDER') {
        ElNotification({
          title: '🔔 新订单提醒',
          message: `订单号：${data.orderNo}，金额：¥${data.totalAmount}`,
          type: 'warning',
          duration: 0,
          onClick: () => {
            router.push(`/orders/${data.orderId}`)
          }
        })
        
        playNotificationSound()
      }
    } catch (error) {
      console.error('解析 WebSocket 消息失败:', error)
    }
  }
  
  ws.onerror = (error) => {
    console.error('WebSocket 错误:', error)
  }
  
  ws.onclose = () => {
    console.log('🔌 WebSocket 已断开，5秒后重连...')
    setTimeout(() => {
      connectWebSocket()
    }, 5000)
  }
}

// 断开 WebSocket
function disconnectWebSocket() {
  if (ws) {
    ws.close()
    ws = null
  }
}

// 在应用启动时连接
onMounted(() => {
  connectWebSocket()
})

onUnmounted(() => {
  disconnectWebSocket()
})
```

```vue
  } catch (error) {
    console.error('获取订单列表失败:', error)
  }
}

// 检查新订单
async function checkNewOrders() {
  if (!notificationEnabled.value) return
  
  try {
    const response = await orderApi.getOrders({ 
      status: 'pending',
      page: 1,
      pageSize: 1
    })
    
    const currentCount = response.total || 0
    
    if (lastOrderCount > 0 && currentCount > lastOrderCount) {
      const newOrderCount = currentCount - lastOrderCount
      
      // 显示通知
      ElNotification({
        title: '🔔 新订单提醒',
        message: `有 ${newOrderCount} 个新订单待确认`,
        type: 'warning',
        duration: 0,
        position: 'top-right'
      })
      
      // 播放提示音
      playNotificationSound()
      
      // 刷新订单列表
      await fetchOrders()
      
      console.log('🔔 检测到', newOrderCount, '个新订单')
    }
    
    lastOrderCount = currentCount
  } catch (error) {
    console.error('检查新订单失败:', error)
  }
}

// 播放提示音
function playNotificationSound() {
  try {
    const audio = new Audio('/notification.mp3')
    audio.volume = 0.5
    audio.play().catch(() => {})
  } catch (error) {
    // 静默失败
  }
}

// 启动/停止通知
function toggleNotification(enabled) {
  if (enabled) {
    startOrderCheck()
  } else {
    stopOrderCheck()
  }
}

// 启动订单检查
function startOrderCheck() {
  checkNewOrders()
  checkTimer = setInterval(checkNewOrders, 30000)  // 30秒
  console.log('🔔 新订单检查已启动')
}

// 停止订单检查
function stopOrderCheck() {
  if (checkTimer) {
    clearInterval(checkTimer)
    checkTimer = null
    console.log('🔔 新订单检查已停止')
  }
}

onMounted(() => {
  fetchOrders()
  startOrderCheck()
})

onUnmounted(() => {
  stopOrderCheck()
})
</script>
```
